# OneTouch

Мгновенная передача файлов между Android и Mac по Wi‑Fi — напрямую, без облака и без QR-кодов.

- **Телефон → Mac:** щипок по фото (или «Поделиться → На Mac») — файл уже на рабочем столе Mac **и в буфере обмена** (⌘V).
- **Mac → телефон:** ⌘C на файле в Finder (или щипок на тачпаде) — на телефоне уведомление **«Получить»**.

## Установка

Все сборки: [Releases → latest-build](https://github.com/saidovahliddin97-oss/onetouch/releases/tag/latest-build).

**Mac** (Apple Silicon и Intel, macOS 13+). В Терминале одной командой:
```sh
curl -L https://github.com/saidovahliddin97-oss/onetouch/releases/download/latest-build/OneTouch-mac.zip -o /tmp/OneTouch.zip && ditto -x -k /tmp/OneTouch.zip /Applications && open /Applications/OneTouch.app
```
В строке меню появится значок ⇄. Разрешите уведомления и «доступ к локальной сети», когда macOS спросит.

**Android** (10+): скачайте на телефоне [`OneTouch.apk`](https://github.com/saidovahliddin97-oss/onetouch/releases/download/latest-build/OneTouch.apk) и установите. Разрешите доступ к фото, уведомления и работу в фоне.

Телефон и Mac должны быть в одной Wi‑Fi сети. Сопряжение не нужно: устройства находят друг друга сами (mDNS).

## Как пользоваться

| Что | Как |
|---|---|
| Фото → Mac | В OneTouch сведите два пальца на фото (в сетке или на весь экран) |
| Любой файл → Mac | В Галерее, Telegram, «Файлах»: Поделиться → **На Mac (OneTouch)** |
| Последнее фото → Mac | Плитка «Фото → Mac» в шторке (добавьте её в быстрые настройки) |
| Файл с Mac → телефон | Выделите файл в Finder → ⌘C, или сведите два пальца на тачпаде. На телефоне нажмите «Получить» |
| Скриншот Mac → телефон | ⌃⇧⌘4 (снимок в буфер) — на телефоне «Получить» |

Полученное на телефоне появляется в Галерее, в альбоме **OneTouch** (документы — в Загрузки/OneTouch). На Mac — на рабочем столе и в буфере обмена.

## Архитектура

```
 Android (Kotlin)                               Mac (Swift, строка меню)
 ┌───────────────────────────┐                  ┌──────────────────────────┐
 │ Галерея со щипком         │                  │ ⌘C / щипок / меню         │
 │ «Поделиться», плитка      │                  │ буфер обмена, уведомления │
 │ Служба (сон в accept())   │                  └────────────┬─────────────┘
 └───────┬─────────▲─────────┘                   JSON-события │ 127.0.0.1:47471
         │         │                             ┌────────────▼─────────────┐
         │         │  mDNS _onetouch._tcp        │ Ядро на Go (onetouch-core)│
         │         └──── POST /v1/offer ─────────┤ TLS :47470, пиннинг       │
         └────────── PUT /v1/files (TLS) ───────▶│ сертификата по отпечатку  │
         ◀───────── GET /v1/offers/{id} (TLS) ───┤                           │
                                                 └───────────────────────────┘
```

- **Поиск устройств:** mDNS/DNS-SD. Mac сообщает в TXT-записи отпечаток своего TLS-сертификата; телефон сверяет его при каждом подключении. Подменить Mac в сети не получится.
- **Телефон → Mac:** `PUT /v1/files` потоком по TLS, запись во временный файл и атомарное переименование.
- **Mac → телефон:** Mac шлёт телефону маленькое «предложение» (имя, размер, отпечаток). Файл телефон забирает сам, по TLS, и только после «Получить».
- **Энергосбережение:** на телефоне служба спит в `accept()`, поиск Mac включается на пару секунд только при отправке, адрес Mac кэшируется. Mac проверяет счётчик буфера обмена раз в полсекунды (одно чтение числа с допуском таймера).

Протокол — `core/internal/transfer/server.go`.

## Структура

```
core/     Go: сетевое ядро + CLI (Windows/Linux: onetouch serve / offer / send)
android/  Kotlin: приложение для Android (Compose, NsdManager, Foreground Service)
macos/    Swift: приложение в строке меню; build.sh собирает OneTouch.app
tools/    установщик для Windows
```

## Сборка

```sh
cd core && go test ./... && go build ./cmd/onetouch
cd android && ./gradlew assembleRelease          # JDK 17+, Android SDK 36
sh macos/build.sh                                 # на Mac: Xcode CLT + Go
```
CI (`.github/workflows/build.yml`) собирает всё и публикует релиз `latest-build` на каждый push.

## Если не работает

- **Телефон пишет «Mac не найден».** Проверьте: одна Wi‑Fi сеть (не гостевая), значок OneTouch есть в строке меню Mac, в «Системные настройки → Конфиденциальность → Локальная сеть» OneTouch включён.
- **«Получить» не приходит при выключенном экране.** Разрешите OneTouch работать в фоне (карточка в приложении). На Xiaomi/Huawei ещё включите «Автозапуск».
- **Журнал Mac:** меню OneTouch → «Журнал» (`~/Library/Logs/OneTouch.log`).
